# UI-автотесты Stellar Burgers

Проект содержит UI-автотесты веб-приложения Stellar Burgers на Python, pytest и Selenium. Тесты проверяют навигацию, работу конструктора и отображение данных в ленте заказов.

## Требования

- Python 3 и `pip`;
- установленный браузер Chrome и/или Firefox;
- доступное приложение по адресу, указанному в `urls.py`;
- для сценариев с авторизацией — действующий тестовый пользователь, данные которого заданы в `data.py`.

Selenium должен уметь запускать выбранный браузер. В актуальных версиях Selenium драйвер браузера обычно управляется Selenium Manager; если он не может скачать или найти драйвер, установите драйвер вручную и добавьте его в `PATH`.

## Установка

Из корневой папки проекта установите зависимости:

```bash
python -m pip install pytest selenium allure-pytest
```

## Запуск тестов

Запустить весь набор тестов в Chrome и Firefox:

```bash
python -m pytest -v
```

Фикстура `driver` параметризована браузерами `chrome` и `firefox`, поэтому тесты запускаются в обоих. Чтобы отфильтровать запуск по одному браузеру, используйте `-k`:

```bash
python -m pytest -v -k chrome
```

```bash
python -m pytest -v -k firefox
```

Чтобы запустить отдельный файл:

```bash
python -m pytest -v tests/test_main.py
```

## Отчёт Allure

Сохранить результаты тестирования и открыть отчёт:

```bash
python -m pytest --alluredir=allure-results
allure serve allure-results
```

Для команды `allure serve` необходима отдельно установленная Allure CLI. Если приложение недоступно, браузерные тесты не смогут проверить UI и завершатся ошибками при переходе или поиске элементов.

## Структура проекта

```text
.
├── conftest.py                 # фикстуры pytest и настройка WebDriver
├── data.py                     # учётные данные тестового пользователя
├── urls.py                     # базовый адрес приложения и маршруты
├── locators/                   # Selenium-локаторы страниц
├── page/                       # Page Object и общие действия страниц
└── tests/                      # тестовые сценарии
```

## Покрываемые сценарии

- переходы из шапки сайта в конструктор и ленту заказов;
- открытие и закрытие окна с деталями ингредиента;
- добавление ингредиентов и проверка счётчиков;
- увеличение счётчиков заказов после создания заказа;
- отображение созданного заказа в ленте.

## Настройка

- Если адрес приложения изменился, обновите `MAIN_PAGE_URL` в `urls.py`. Остальные адреса страниц формируются относительно него.
- Для сценариев, которым требуется вход, задайте действующие тестовые данные в `data.py`. Не используйте в тестах личные или производственные учётные данные.
- Если структура страницы изменилась, обновите соответствующие селекторы в файлах `locators/`.
